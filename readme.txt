A developer utility block for previewing, sanitizing, and exporting SVG block icons.

== Description ==

WP Block Icon Preview is a developer utility WordPress block that helps block developers:

* Paste and preview raw SVG code
* Sanitize SVGs for WordPress.org compatibility
* Export as JSX, TSX, or block.json string format
* Understand compatibility issues with diagnostic messages

This is an approximate/compatibility-oriented preview — it does not promise exact WordPress.org rendering.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/wp-block-icon-preview` directory, or install through the WordPress plugins screen.
2. Activate the plugin through the Plugins screen in WordPress.
3. Add the "WP Block Icon Preview" block to any post or page.
